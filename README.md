# agentic-transfer-twin

A research prototype: workflow, network, and coordinator agents plan scientific-workflow data
transfers over a simulated network, using tools exposed through an MCP server, and are compared
against simple rule-based baselines. Built as a preliminary trial for the SciNet project.

**Status:** under construction — see [`docs/BUILD_LOG.md`](docs/BUILD_LOG.md).

Workflow traces come from the [WfCommons WfInstances](https://github.com/wfcommons/WfInstances)
project (LGPL-3.0); see [`data/NOTICE.md`](data/NOTICE.md).
